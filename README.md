# spatial-transcriptomics-interactive-tutorial

**🌐 Live demo / 線上瀏覽**: <https://charlene717.github.io/spatial-transcriptomics-interactive-tutorial/>

## 中文簡介

空間轉錄體學互動式教學。15 章涵蓋 Visium、Visium HD、Xenium、MERFISH、CosMx、Slide-seq、Stereo-seq 等平台，從 spot 到 subcellular 解析度，雙語並陳。

## English Description



A bilingual (繁中 / English) interactive tutorial covering the modern Spatial Transcriptomics analysis stack — from Visium / Visium HD / Slide-seq / Stereo-seq (spot-based) through Xenium / MERFISH / CosMx (image-based, single-cell resolution).
